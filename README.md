# 籌碼力度每日選股

依老墨「法人力度指標」公開說明重建的全市場選股程式：
**法人買賣超 ÷ 發行股數（佔股本比）→ 以過去 N 日標準化 → 超過門檻才算「顯著買超」**。
同樣買一萬張，小型股會被標出、大型股不會——只留下「有份量的買超」。

> 原 XQ 腳本為加密檔，本程式依說明頁的參數與邏輯自行實作，數值可能與原版不完全相同。

## 每天自動跑（GitHub Actions，免開電腦）

1. 本專案就是這個 private repo（`yinruei/chip-force`），排程檔為 `.github/workflows/daily.yml`。
2. 到 repo 的 **Actions** 頁選「籌碼力度每日選股」，按一次 **Run workflow** 做第一次回補（約 10–20 分鐘）。
3. 之後每個交易日台北時間 **17:47** 自動執行，結果在：
   - `output/latest_三大法人.md`、`output/latest_投信.md`（最新一天）
   - `output/YYYYMMDD_*_顯著買超.csv`（完整清單）
   - 每次執行的 Actions 摘要頁也會直接顯示表格
4. 想在手機收到通知：repo 右上 **Watch → Custom → Actions**（或看 commit）。

## 本機執行

```bash
python chip_force.py                         # 三大法人，W=60、k=2.0
python chip_force.py --investor 投信 --mode 穩健   # 投本比
python chip_force.py --investor 外資 --window 120 --k 2.5 --confirm 2
python chip_force.py --date 2026-09-29       # 指定日期
```

只用 Python 標準函式庫，不需安裝套件。

## 參數（對應原指標）

| 參數 | 對應原指標 | 可選 | 預設 |
|---|---|---|---|
| `--investor` | 看哪個法人 | 三大法人／外資／投信／自營 | 三大法人 |
| `--window` | 極端值比較區間 | 20／60／120 | 60 |
| `--k` | 極端靈敏度（越小越靈敏） | 1.5／2.0／2.5 | 2.0 |
| `--confirm` | 訊號確認天數 | 1／2／3 | 1 |
| `--mode` | 極端訊號模式 | 靈敏／穩健 | 靈敏 |
| `--min-ratio` | 穩健模式最低佔股本比(%) | 任意 | 0.05 |
| `--min-volume` | （自加）排除冷門股 | 最低當日成交張數，0＝不篩 | 1000 |
| `--fast` / `--slow` | 近期／長期法人動向均線 | 10/20/30、40/60/120 | 20 / 60 |

## 判斷方式

- 佔股本比 `r = 買賣超股數 / 發行股數 × 100%`
- 力度 `z = (今日 r − 過去 W 日 r 平均) / 過去 W 日 r 標準差`（不含當日）
- **顯著買超**：`z ≥ k` 且 `r > 0`，連續 `confirm` 天成立（穩健模式另需 `r ≥ min-ratio`）
- **買方轉強**：佔股本比的快線上穿慢線，但尚未達顯著門檻
- **成交張數門檻**：當日成交張數 < `--min-volume`（預設 1000 張）的股票不列入，濾掉只靠幾十張就衝高 z 的冷門股。只抓篩選當日的成交量（證交所 MI_INDEX、櫃買 dailyQuotes）；某市場抓不到時該市場不套門檻，並在日誌顯示警告
- 僅納入 4 碼普通股，排除 ETF／特別股／權證

資料來源：證交所 T86、MI_QFIIS；上櫃資料取自櫃買中心（介面若改版會自動略過，只跑上市）。
